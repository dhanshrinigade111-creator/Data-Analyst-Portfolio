# Pizza Hut Sales Analysis

## Project Overview
This project analyzes Pizza Hut sales data using SQL to understand sales performance and customer ordering patterns.

## Project Objectives
- Calculate total orders.
- Calculate total revenue.
- Identify the highest-priced pizza.
- Analyze orders by hour.
- Understand pizza sales performance.

## Tools Used
- MySQL
- SQL

## Skills
- SQL Queries
- Joins
- Aggregate Functions
- Data Analysis
- Business Insights
